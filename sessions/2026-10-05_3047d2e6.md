The intake ran at 19:11 and found your brief but no messages from you, so it switched to work mode. The tool the brief asks for is now built.

- **What it does:** `notes-to-site NOTES -o site` turns a folder of Markdown notes into a static site. You get one page per note, an index page, `[[note]]` and `[[note|label]]` links between notes, and a "Pages that link here" section at the bottom of each page. Links to notes that don't exist are marked on the page and printed as warnings.
- **Constraints:** it uses only the Python standard library, with a hand-written Markdown converter, since Python has none built in. It runs on Python 3.9 and newer.
- **Tests:** 51 unit tests pass, including an end-to-end build of a small `example/` notes folder. The automated tests on GitHub passed on Linux, Windows and macOS with Python 3.9 and 3.13. The README covers usage and the link syntax.
- **Repo:** everything is pushed to the private GitHub repo `EmmaLeonhart/markdown-notes-static-site`.

I made some decisions myself instead of asking, and wrote them down in `INTENT.md`:
- A note's title comes from a `#` heading on its first line, otherwise from its file name.
- Links match note names regardless of capitalisation.
- Building never deletes old pages from the output folder.
- `[[note#section]]` links to the note, not to the section.
