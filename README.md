# notes-to-site

> Started with [cleanvibe](https://github.com/EmmaLeonhart/cleanvibe) on 2026-10-05.

A small command-line tool (Python standard library only) that turns a folder of
Markdown notes into a static HTML site: one page per note, an index page, and a
"pages that link here" backlinks section at the bottom of each page. Notes link
to each other with `[[note name]]`.

**Status:** in progress. The plan is in `queue.md`; the original brief is
`data_lake/brief.md`.

## Working on it

Run `cleanvibe` in this folder (or double-click `!runClaude.bat` on Windows) to
open a new Claude session here. It starts with Remote Control on, so you can
continue from the Claude app or web. Earlier sessions are in `sessions/`.
